# 豐富・苗栗・南勢列車動態監測

使用者於2026-10-03授權從現在開始監測三站所有列車，包含專列。
每60秒抓取一次官方TDX TrainLiveBoard，三站代碼3150、3160、3170。
不設定旅客列車、時刻表車次或車種白名單。未有班表、未知車種也保留。
「專列／觀光列車／迴送／貨列」只在來源提供證據時辨識，不按車號猜測。
車種是官方服務類別，不能保證具體EMU型號、牽引機車、彩繪編組。

每次工作保存snapshots.jsonl、events.json、events.csv、summary.json。
CSV欄位包含車次、車種、方向、站點、停靠分類、官方事件更新時間、
第一次收到時間、事件距收到的秒數、來源過期、初始快照、誤點及班表註記。
去重只在同次工作內進行。跨工作合併時以車次、站點、事件更新時間及狀態去重。
初始快照可能是啟動前已發生的事件，不能當新通過。
沒有班表標記停靠方式待確認。凌晨同車次兩個營運日衝突時不猜測。
所有紀錄都是站點位置事件，並非園區拍攝點或月台中點實測通過時間。

GitHub Actions每小時17分啟動，每次65筆約64分鐘，容許重疊以減少交接缺口。
首次推送工作流程立即啟動；GitHub排程可能延遲或漏啟動，不保證無縫。
輪詢間內列車若已回報下一站，本站事件可能被覆蓋；公開API未回報列車無法記錄。
快照內0筆只代表當次沒有三站紀錄，不代表三站期間沒有火車。
HTTP錯誤／配額限制會停止該次工作並保存健康狀態；後续工作再嘗試。
憑證沿用後端TDX_CLIENT_ID／TDX_CLIENT_SECRET，不保存至檔案。
每個完整工作65次動態請求，加授權及最多兩日班表；每天約1560次動態請求。
原始紀錄以GitHub Actions artifact保存90天，尚未建立永久彙整資料庫。
本工作不修改前台時刻表、不將事件時戳偽裝成精準通過時間。

驗收：離線單元測試、首次真實動態工作紀錄均需檢查。
後續建議檢查三站鏈、6725專列、來源延遲及漏報比例，再調整資料來源／頻率。
